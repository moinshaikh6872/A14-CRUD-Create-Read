# A14-CRUD-Create-Read
An HTML form that posts a new record to your API, and a list on the page that shows everything currently stored.

## Instructions
1. Install dependencies: `pip install -r requirements.txt`
2. Run the FastAPI backend: `uvicorn main:app --reload`
3. Open `index.html` in your web browser (double-click the file) to interact with the API.
